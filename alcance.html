El sistema consiste en una plataforma web con autenticación obligatoria, enfocada en ofrecer acompañamiento emocional y permitir la formación práctica de estudiantes de psicología.

Incluye:

  • ✔ Sistema completo de test de evaluación (5–8 preguntas)
  • ✔ Recomendaciones personalizadas: videos, ejercicios, artículos
  • ✔ Gestión completa de usuarios y contenido multimedia
  • ✔ Panel administrativo para profesionales
  • ✔ Formularios de contacto y seguimiento
